# 戦国 千二百万分の一

戦国の世（応仁の乱の1467年〜関ヶ原のころの1600年）に、千二百万人のうちの誰かとして生まれ、死ぬまでを生きる人生シミュレーションゲームです。

## 遊び方

- **今すぐ遊ぶ：https://uruga1200.github.io/sengoku-1200man/**
- ブラウザで `index.html` を開くだけでも遊べます（インストール不要・無料）。
- 「生まれる」：身分も性別も国も運しだい。
- 「武士として生まれる」：必ず武家の男子として生まれ、武士の道を歩みます。

## 特徴

- 百姓・武家・町人・寺の子・公家として生まれ、足軽、侍、大名、浪人、商人、茶人、僧、尼、公家、歩き巫女などの人生を送る
- 1年に何度も起こる、季節ごとの戦国あるあるイベント
- 桶狭間・本能寺・関ヶ原・大坂の陣などの史実の分かれ道
- 子と孫の行く末、辞世の句、戒名、過去帳
- ドット絵の場面、難しい言葉の読み仮名と※解説、貫文の現代の金額の目安

## 注意

- 史実をもとにした創作です。人物や出来事の細部にはフィクションを含みます。
- 金額の換算（1貫文＝約6万5千円）は、当時の米の値段から計算した目安です。
- 過去帳は、遊んだ人それぞれのブラウザの中にだけ保存されます。
